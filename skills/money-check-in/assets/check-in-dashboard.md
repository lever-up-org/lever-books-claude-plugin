# Check-in dashboard brief

Start from the HTML in `dashboard.md` in this folder and fill its data block. Keep the same layout every
week so changes stand out.

- **Title:** one sentence, for example "You spent $612 this week, $80 less than last week".
- **KPIs:** Spent this week (the headline, with its change), Available, Bills due before next
  week.
- **Sections, in order:**
  1. `bars`: the top five categories this week, last week as the grey tick.
  2. `calendar`: the next 14 days, each bill and regular charge as a chip.
  3. `table`: worth a look, up to three rows (item, amount, why), marked `warn`.
  4. `table`: the three things to do this week.
- **Footer:** nothing extra; the template adds the source and the advice line.
